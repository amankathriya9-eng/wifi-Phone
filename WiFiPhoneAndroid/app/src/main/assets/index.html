Ye code caller ko wapas bhejo. Wo apne device par paste karke connect karega, phir call jud jayegi.

💡 Ye same WiFi/local network par kaam karta hai — mobile data ki zaroorat nahi. Dono devices ek hi router se connected hone chahiye. Ek device "Call banao" karega, doosra "Call join karo".
